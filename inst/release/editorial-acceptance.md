# Documentation editorial acceptance rubric

Documentation is accepted only when every item below has been checked against
the rendered page rather than source text alone.

- Claims are concrete and traceable to package behavior or named evidence.
- Terminology is consistent; FDP+ is not presented as a universal guarantee.
- Each concept has one authoritative explanation with links instead of copies.
- Prose avoids stock promotion canned previews and unsupported adjectives.
- Examples execute unless they are explicitly labelled external interactive or
  protocol-only code with a named deterministic contract test where applicable.
- Package-local links resolve and external links are checked during site review.
- A final read-through of every rendered page confirms headings figures code
  output disclosures and limitations in context.
