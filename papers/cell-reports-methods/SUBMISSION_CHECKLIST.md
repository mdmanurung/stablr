# Cell Reports Methods submission checklist

## Complete before upload

- [ ] Confirm target article type with Cell Reports Methods editorial guidance.
- [ ] Add final author list, affiliations, ORCID IDs, and corresponding-author
  details.
- [ ] Add acknowledgments and funding.
- [ ] Confirm declaration of interests.
- [ ] Decide whether a DOI-bearing archive is required; if yes, create one and
  update `RESOURCE_AVAILABILITY.md`.
- [ ] Convert `MANUSCRIPT_DRAFT.md` to the journal upload format.
- [ ] Confirm reference formatting and add complete bibliographic details.
- [ ] Confirm Figure 1 and Figure 2 meet journal resolution requirements.
- [ ] Confirm all artifact filenames in `ARTIFACT_MANIFEST.md` exist.
- [ ] Run final naming audit: `stablr`, not `costablr` or `co-stablr`.

## Claims audit

- [x] Does not claim a new STABL method.
- [x] Does not claim universal superiority over DIABLO or other multi-omic
  methods.
- [x] States that TCGA nested-CV vs DIABLO is deferred.
- [x] Frames Python/R differences as implementation-level and validates
  selection/ranking concordance.
- [x] Points to the v0.1.0 GitHub release and live pkgdown site.

## Suggested final title options

2. `stablr: an R package for sparse, reliable omic biomarker discovery`
