# Highlights and eTOC

## Highlights

- `stablr` brings STABL-style biomarker discovery with FDP+ control to R
- The package supports knockoff/random-permutation null features and `glmnet`
  learners
- Multi-omic train/validation, cross-validation, and fusion workflows are
  exposed through documented APIs
- OOL validation recovers 7/7 Python tutorial selected features at
  publication-scale settings

## eTOC blurb

`stablr` is a pure-R implementation of STABL-style stability selection for
omics biomarker discovery. The package combines bootstrap sparse modeling,
artificial-feature FDP+ calibration, multi-omic workflows, and manuscript-ready
diagnostics. Validation on Onset of Labor proteomics data recovers all Python
tutorial selected features with concordant feature rankings.
