2. Correct and seal the SCI/methodology and OOL review materials.
3. Authenticate and bind actual reviewer decision records without supplying a
   reviewer or accepting a decision.
4. Harden OOL score, provenance, runtime, closure, and verification behavior.

## Authorization

Allowed:

- Edit the package repository and the sibling experiments repository for the
  frozen plan.
- Preserve and incorporate the current dirty changes; do not discard them.
- Run local tests, builds, checks, documentation generation, and pkgdown.
- Create local branches, atomic commits, fresh campaign directories, manifests,
  seals, and a local experiments Git bundle.
- Push the package release branch and open a draft PR only if existing
  noninteractive credentials work; never force-push.

Approval required:

- Supplying or registering the independent reviewer trust root.
- Accepting either scientific decision.
- Scheduler submission for definitive methodology, late-fusion, or OOL runs.
- Win-builder, macbuilder, R-hub, or other external-service submissions.
- Credential changes, branch-protection changes, or other repository-admin
  actions.

Forbidden or out of scope:

- Implementing a scientific formula, multiplicity policy, replicate count,
  applicability decision, or promotable contract v2 without the accepted SCI
  record.
- Running full OOL without its authenticated accepted decision.
- Rewriting or deleting historical/negative evidence.
- Editing or committing `papers/cell-reports-methods/`.
- CRAN submission, email confirmation, tagging, GitHub release publication,
  pkgdown deployment, post-acceptance monitoring, or version bump.
- Manuscript, TCGA/DIABLO, Cox/Poisson cooperative, or unrelated feature work.
