- one-build exact-candidate CI with Linux release/devel/oldrel, macOS release,
  Windows release, R 4.1, and clean-install receipts; and
- an external evidence-only promotion validator requiring both authenticated
  decisions, package/OOL candidate and runtime equality, passing platform and
  specialist receipts, and final non-draft CRAN-comments identity.

Ordinary PR coverage remains separate. Instrumented `covr` coverage necessarily
reinstalls an instrumented build, so it is not represented as an exact-candidate
receipt and cannot satisfy promotion evidence. This preserves the stronger rule
that candidate-workflow downstream jobs do not rebuild the source artifact.
