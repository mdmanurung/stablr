## Pre-freeze engineering verification

Use R4_51 and the preserved optional-dependency library where required:

```sh
Rscript --vanilla -e 'devtools::document(); devtools::test()'
R CMD build .
R CMD check --as-cran stablr_0.1.1.tar.gz
```

Also run focused release-evidence, SCI-04, artificial-feature, provenance,
methodology, late-fusion, and CLI tests; inspect every skip; build pkgdown; and
review the complete diff. Smoke OOL output tests mechanics only and is always
non-promotable.

Merge through a green pull request. Do not force-update `main`. The obsolete
historical force-with-lease promotion procedure is retired.

## Immutable candidate and package evidence

Build the source artifact on current R from the final `main` SHA, hash and
download that exact CI artifact, verify its contents, install it in a clean
library, and copy it to a content-addressed read-only store. Any tracked change
creates a new candidate and invalidates later evidence.

The only package release-evidence interface is:

```sh
Rscript --vanilla inst/analysis/release_evidence_cli.R prepare \
  --candidate /absolute/frozen/stablr_0.1.1.tar.gz \
  --runtime /absolute/R4_51/Rscript \
  --store /absolute/new/release-store \
  --out-ref /absolute/context-reference.json

Rscript --vanilla inst/analysis/release_evidence_cli.R run \
  --context-ref /absolute/context-reference.json \
  --validation-id methodology \
  --out-ref /absolute/methodology-packet-reference.json

Rscript --vanilla inst/analysis/release_evidence_cli.R assemble \
  --context-ref /absolute/context-reference.json \
  --packet-ref /absolute/methodology-packet-reference.json \
  --packet-ref /absolute/late-fusion-packet-reference.json \
  --out-ref /absolute/release-evidence-reference.json
```

Run `late_fusion` with a second `run` invocation before assembly. The
methodology and late-fusion validations may run concurrently because each owns
a no-replace attempt against the same immutable context.

The resulting package Release Evidence Packet is necessary but not sufficient
for v0.1.1 promotion.

## Separate OOL v3 evidence

Run the independently approved v3 generator from `stablr-experiments` against
the identical tarball SHA. The full profile requires the signed decision,
external reviewer trust root, and complete review-bundle manifest,
the frozen 150-by-1,317 input/reference, 500 bootstraps, 10 lambdas, seed 42,
model-X equicorrelated generation with Ledoit-Wolf covariance and no fallback,
Jaccard at least 0.80, Spearman at least 0.90, and FDP-threshold delta at most
0.05.

A completed failed gate is sealed immutable negative evidence and stops the
release. A crash remains unsealed and may be retried only with identical
settings in a new directory.

## Platform and promotion gates

After both scientific packets pass for the identical candidate, require the
exact-candidate GitHub matrix, local current-R check, Win-builder, macOS, and
R-hub specialist checks. Package defects require a new candidate and repeated
scientific validation.

Create and verify the external promotion record binding the tarball, package
packet, OOL packet, platform receipts, accepted CRAN comments, and human
approval. Only that sealed outer record authorizes CRAN submission.

CRAN submission, maintainer email confirmation, annotated tagging, GitHub
publication, branch-protection changes, and the 48-hour post-acceptance window
remain explicit external actions. Bump to `0.1.1.9000` only after that window.
