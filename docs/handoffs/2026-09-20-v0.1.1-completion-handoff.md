## Scientific status

SCI-04 v3 is implemented as an owner-authorized proposal: 600 replicates per
applicable cell, a one-sided per-cell Hoeffding bound at alpha 0.05, threshold
0.10, and an intersection-union decision over 44 applicable null cells. The
explicit 96-cell matrix excludes eight infeasible fixed-X/high-dimensional
cells. This is executable engineering, not independent acceptance, and it is
not active in release-contract v1.

The corrected `knockoff_equi` path implements the pinned Python reference's
Gaussian model-X equicorrelated semantics using a scikit-learn-compatible
Ledoit-Wolf covariance estimate. `knockoff` remains fixed-X and
`knockoff_mvr` remains separate.

The current-source Python parity tests passed. Live results at HEAD were:

- 41/41 metrics matched, with maximum absolute error `1.387779e-17`;
- the FDP+ curve matched exactly;
- Gaussian, binomial, and multinomial lasso had Spearman/Jaccard `1/1`;
- Gaussian elastic net had Spearman `0.9089285714` and Jaccard `0.75`; and
- all four solver cases had 5/5 top-feature overlap.

This supports deterministic algorithm and ranking/support parity with the
pinned Python STABL reference. It does not establish coefficient identity,
universal calibration, predictive equivalence on arbitrary datasets, or
runtime-speed parity. See
`tests/testthat/fixtures/python_parity/README.md` for the exact contract and
limitations.

End-to-end OOL parity remains unproven. Historical v2 is permanent negative
evidence: Jaccard `0.778`, Spearman `0.785`, FDP-threshold delta `0.08`, and an
old generator mismatch. The only v3 result is a deliberately non-promotable
two-bootstrap smoke against provisional tarball SHA `58326937...`. Its
generator, preprocessing, and lambda alignment passed, but its numerical
values were Jaccard `0.50`, Spearman `0.312786`, and threshold delta `0.08`;
the full-profile gate failed. The sealed smoke packet is under
`../stablr-validation-artifacts/0.1.1/completion-20260920-fac5a622/smoke/ool-v3-smoke-20260920-58326937/`.
